git init . 			 -> Cria um repo git na pastqa atual 
git status 			 -> Mostra o status do trabalho (de cada arq)
git add nome_arquivo -> Adiciona arquivo para ser comittado, se usar add . adiciona tudo da pasta que vc esta 
git commit -m "msg"  -> Faz commit do que estava para ser 
git log  			 -> Mosta todo o histórico de commit 
git add. 			 -> Vai adicionar tudo que esta na pasta atual 
git checkout -b (nome) -> cria e troca de branch

git pull origin main  -> recebe os arqs da origem
git push origin main  -> envia as coisas para a origem 
git fetch  -> usado para receber as branchs que estão no repositório remoto 





fluxo do trabalho
1.criar dir do projeto
2.inicia o git dentro do diretório criado (git. init)
3.edita ou cria arqs
4.git status
5.git add <nome arquivo>
6.git status
7.git commit -m "mensagem estranha"
8.git status
9.volta para o passo 3
